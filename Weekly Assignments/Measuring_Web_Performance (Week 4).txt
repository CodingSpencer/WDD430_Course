Measuring Web Performance

Definitions:
- Session Window: A burst of layout shifts on a page


Part 1
1. Setup
Performance Score: The large circled number (0-100).
LCP (Largest Contentful Paint): Time in seconds. Goal: < 2.5s.
Notes: Basically when the page becomes visible to the user and has 4 subparts: TTFB, Load Delay, Load Time, and Render Delay
CLS (Cumulative Layout Shift): The shift score. Goal: < 0.1.
CLS Calculation Equation: layout shift score = impact fraction * distance fraction
Ex. - Item takes up 50% of screen and move from the top to 25% of the way down the screen would create this equation 0.75 * 0.25 = 0.1875
Notes: Measures layout shifts from one rendered frame to the next. Can be caused by page loading asynchronously or DOM elements beig added to a page before the existing content.
TBT (Total Blocking Time): Time in milliseconds.
Notes: This is the amount of time that a page is blocked from responding to user input. (Time after 50 ms). Common long tasks are often caused by JS loading, parsing, or execution. Can also be caused by inefficient JS statements.
Speed Index: Time in seconds.

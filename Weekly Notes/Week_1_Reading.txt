Web Vitals
- User experience will often correlate with how long a web site will live on the web
- Web Vitals was an initiative by Google to provide standard guidance to help developers test their sites
- Core Web Vitals
	- These are web vitals that apply to all web pages
		- Each one will be a specific part of the UX, will be measurable in the field, and will reflect a realworld example of a user-centric outcome.
	- Current 3 Aspects are Loading, interactivity and visual stability
	- Each one is measured by one of the following:
		- LCP (Largest Contentful Paint): 2.5 second from page beginning to load (good UX)
		- INP (Interaction to Next Paint): 200 milliseconds or less (good UX)
		- CLS (Cumulative Layout Shift): 0.1 or less (good UX)
- Three Types of Metrics before added to web vitals: Experimental, Pending, and Stable
